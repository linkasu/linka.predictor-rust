# Evaluation protocol v1 (declared before measurements)

The primary metric is clean-text KSR = 1 - paid actions / typed grapheme count. A typed space is one paid action. Suggestions are considered only by applying the serialized public response with independent UTF-16 semantics; choose a useful matching target prefix only when its saved typing exceeds selection cost. Report selection costs 1, 2 and 3 independently. Empty input produces no free first suggestion. Corrections use separate synthetic-error recall; never mix them into clean KSR.

Compare frequency-only and contextual models on identical complete phrase groups. The primary quality statistic is the unweighted mean of per-phrase KSR at selection cost 1; also report aggregate action-weighted KSR and the cost-2/3 sensitivity. The independent resampling unit is a connected component joining duplicate normalized segment families with their original source utterances, not each punctuation-delimited segment. Sample the lowest hashed component keys, include all their phrases, and bootstrap paired components (10000 resamples, deterministic seed 906). Each resample computes sum of phrase differences divided by total resampled phrase count, preserving the primary unweighted per-phrase estimand rather than substituting a mean of component means. Lower bound >0 is required to claim a demonstrated contextual gain. An interval containing zero means inconclusive, not a pass. Next-word top1/top5/MRR, prefix completion and candidate recall must have explicit denominators. Missing measurements remain missing.

Use grouped Tatoeba dev only for choices. Test is opened only after a frozen manifest binds source tree/revision, executable, model, resolved config, splits and evaluator hashes. Before test, record the selected candidate and final regression limits. No changes to code/config/model or policy after test; a failed candidate is reported, not silently retuned. Original household phrases are a small smoke set, not a representative AAC benchmark.

Final decision thresholds, predeclared before dev results: evaluate at least 200 distinct held-out independent components for the primary comparison (200 segments from one utterance count as one component); all mandatory deterministic contract fixtures must pass. The count baseline must have real embedded positive counts bound to its complete frequencies sidecar, not merely a neighboring filename. The lower paired 95% CI of contextual-minus-frequency mean KSR must exceed zero. With corrections enabled, clean mean KSR must not fall more than 0.01 absolute below the same contextual model with corrections disabled. After the fixed personal replay, general nonpersonal mean KSR must not fall more than 0.01 absolute below its unpersonalized value, and the explicitly new OOV fixture must improve candidate availability only after its causal confirmation. Report correct-word displacement separately; missing displacement measurements prevent a complete quality claim. These rules cannot be relaxed after viewing test results.

Prepared `{train,dev,test}.groups.tsv` files align one-to-one with their text files: `SHA256(normalized_phrase) TAB component_sha256`. Grouping protocol is `duplicate-original-components-v1`. Verify alignment and bind group-map SHA256, actual sampling limit and sampling/grouping protocol in the frozen manifest before claiming final test. A fixture without document metadata may use normalized-phrase groups, explicitly labeled unverified for original-utterance independence. An operation/candidate-truncated oracle cannot certify full-search recall; report it as inconclusive, not a complete denominator.

Mandatory functional evidence: independent KenLM log10 parity on tiny and full-model samples (absolute tolerance 0.0001); independent UTF-16 mixed-span projection; full-scan tiny candidate oracle; letter insert/delete/substitute/transpose; split/join and combined errors; no crossing sentence boundaries; personal event/utterance idempotence, read-only queries, separate confirm/selection counts, reopen/clear and write failure; corruption/bounds validation; interruption/resume identity and exclusive trainer slot; fresh cached reproduction. Unit tests alone do not establish E2E completion.

Resource qualification uses release code on book.local, no concurrent trainer, limit=5, five separate mode slices (completion, next-word, letters, spaces, mixed). Each slice: at least 50 warmup requests and 1000 measured requests, fixed input file/hash, every duration retained. Record p50/p95/p99, power/load metadata, validation/open/first query separately and limit=100 separately. Main gate: each warm p95 <=100 ms, package plus mandatory notices <=500000000 bytes. Measure training peak RSS and runtime RSS; do not substitute mmap file length for memory usage. Mac results do not qualify Android or another OS.

Actual acceptance requires independently inspected measurements on the exact frozen state. This protocol is not a statement that production quality has been accepted.
